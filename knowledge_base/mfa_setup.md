# Multi-Factor Authentication (MFA) Setup and Recovery
Category: Account Access

## Overview
All employees must use multi-factor authentication when signing in to email, VPN, and business systems. The company supports authenticator apps. SMS codes are not supported.

## First-Time Setup
1. Install an authenticator app on your phone.
2. On a computer, open https://selfservice.acme.example/mfa and sign in.
3. Click Add device and scan the QR code with the app.
4. Type the 6-digit code shown in the app to confirm.

## Getting a New Phone
Set up the app on the new phone before you wipe or return the old phone. Open the self-service MFA page, remove the old device, and add the new one using the steps above.

## Lost or Broken Phone
Contact the IT Service Desk as soon as possible. An agent will verify your identity with your employee ID and your manager's name, then reset your MFA registration. A temporary bypass code is issued that is valid for 8 hours. Register your new device within that time.

## Codes Are Rejected
Set the phone to automatic date and time. Wait for the next code to appear and type it without delay. If push approvals do not arrive, open the app manually and use the code instead.

## Security Rules
Never share a code or approve a request you did not start. Report unexpected approval requests to the Security team immediately.
