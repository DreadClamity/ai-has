# Software Installation and Access Requests
Category: Software and Licensing

## Overview
Software is grouped into standard, restricted, and prohibited. The group decides whether approval is needed.

## Standard Software (No Approval Needed)
Microsoft 365, Zoom, Google Chrome, 7-Zip, and Adobe Acrobat Reader can be installed by any employee from Software Center on a company laptop.

## Restricted Software (Manager Approval Needed)
Adobe Creative Cloud, Visual Studio, Tableau, and administrator rights in Jira are restricted. To request one, submit a helpdesk request that includes the software name, a business reason, and your manager's name. The manager approves by email within 2 business days. IT provisions the license within 1 business day after approval.

## Prohibited Software
Unapproved file-sharing tools, remote desktop tools, cracked or pirated software, and cryptocurrency miners are not allowed and may be removed automatically.

## Shared Folder and System Access
Access to a shared folder or business system must be approved by its owner. Submit a request that names the folder or system and the owner. Access is normally granted within 1 business day after the owner approves.

## Escalation
If a standard application fails to install from Software Center, collect the error message and create a ticket for the Desktop Support team.
